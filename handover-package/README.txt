RIFF — UI/UX DESIGNER HANDOVER PACKAGE
======================================

For: the UI/UX designer taking over Riff's visual & interaction design.

WHAT'S IN THIS FOLDER
---------------------
1. VISUAL_TOUR.html          → START HERE. Double-click to open in any web browser.
                               An annotated, click-through tour of all 33 screens
                               (live captures) with design notes and opportunities.
                               NOW INCLUDES the new Projects (Kanban) + Studio tools
                               and the public Link-in-Bio page.

2. HANDOVER_FOR_DESIGNER.md  → The written handover: product context, how to run the
                               app locally, the full screen inventory with file paths,
                               the current design system (color tokens, typography,
                               components), constraints, and open questions. Updated
                               with the new Projects + Studio surfaces.
                               Open in any Markdown viewer, VS Code, or a text editor.

3. FEATURE_GUIDE.md          → How to USE the new Projects + Studio tools, feature by
                               feature, with step-by-step flows. Read this to drive the
                               new surfaces before redesigning them.

4. screenshots/              → The 33 full-page PNG captures used in the visual tour,
                               numbered 01–33 in walkthrough order. Usable on their own.
                               (24–33 are the new Projects/Studio/public screens.)

HOW TO SHARE
------------
Keep this folder together (zip it if emailing) so VISUAL_TOUR.html can find the
screenshots. Opening VISUAL_TOUR.html is the fastest way to see the whole product.

CONTEXT
-------
The app is fully functional but the UI is deliberately minimal and engineer-built —
a dark, utilitarian baseline. The goal of this handover is to have a designer elevate
the look, feel, and interaction design. Nothing in the current UI is final.
